# FreeSIS 최초 이력 백필

`freesis_credit.csv` 또는 `freesis_credit.xlsx`를 이 폴더에 넣을 수 있습니다.

필수 열은 다음 두 종류입니다.

- 날짜: `일자`, `날짜`, `기준일`, `date` 중 하나
- 전체 신용융자: 열 이름에 `신용융자`와 `전체` 또는 `합계`가 포함

예시:

```csv
일자,신용거래융자-전체
2025-01-31,"18,123,456"
2025-02-28,"18,456,789"
```

단위는 원·백만원 어느 쪽이든 YoY와 하락률 판정에는 영향이 없지만, 기간 전체에서
같은 단위를 사용해야 합니다.
